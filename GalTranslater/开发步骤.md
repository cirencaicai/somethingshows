# GalGame OCR 实时翻译工具开发指南（Linux）

## 📌 项目目标

实现一个工具：

> 框选 GalGame 文本区域 → 自动截图 → OCR识别日文 → 翻译成中文 → 显示结果

---

## 🧠 一、整体流程

```
框选区域 → 截图 → OCR → 翻译 → 显示
```

---

## ⚙️ 二、环境准备

### 1. 安装截图工具

```bash
sudo pacman -S grim slurp
```

* `slurp`：用于框选区域
* `grim`：用于截图

---

### 2. 安装 OCR

```bash
sudo pacman -S tesseract tesseract-data-jpn
```

---

### 3. 安装 HTTP 请求库（用于翻译 API）

```bash
sudo pacman -S curl
```

（C语言使用时建议安装 libcurl）

---

## 🖼️ 三、步骤详解

---

### Step 1️⃣：获取截图区域

运行：

```bash
slurp
```

输出类似：

```
100,200 800x200
```

表示：

```
x=100, y=200, width=800, height=200
```

---

### Step 2️⃣：截图指定区域

```bash
grim -g "100,200 800x200" text.png
```

---

### Step 3️⃣：OCR 识别日文

```bash
tesseract text.png stdout -l jpn
```

输出：

```
こんにちは
今日はいい天気ですね
```

---

### Step 4️⃣：调用翻译 API

（示例：伪代码）

```c
// 使用 libcurl 发送请求
POST https://api.xxx.com/translate

参数：
text=こんにちは
from=jp
to=zh
```

返回：

```
你好
```

---

### Step 5️⃣：显示翻译结果

初版可以直接：

```bash
printf("翻译结果: %s\n", result);
```

后续可以用 GUI（如 raylib）显示。

---

## 🔁 四、自动循环识别（核心功能）

实现循环：

```
while (运行中) {
    1. 截图
    2. OCR
    3. 如果文本变化：
        → 翻译
        → 显示
    sleep(500ms)
}
```

---

## 🧹 五、优化建议

### ✅ 1. 去重

```c
if (strcmp(new_text, last_text) == 0) {
    // 跳过
}
```

---

### ✅ 2. 文本清洗

去掉：

* 空格
* 特殊符号
* OCR误识别字符

---

### ✅ 3. 分行处理

GalGame 常见逐行显示：

```
第一行
第二行
```

建议拼接或逐行翻译。

---

### ✅ 4. 识别频率控制

建议：

```
每 300ms ~ 1000ms 截图一次
```

避免性能问题。

## ⚠️ 七、常见问题

---

### ❌ OCR 识别错误

解决：

* 提高截图清晰度
* 放大文本区域
* 使用更高质量字体

---

### ❌ 翻译重复

解决：

* 加去重逻辑

---

### ❌ Wayland 无法截图

解决：

* 使用 `grim + slurp`
* 或切换到 X11

---

## 🎯 八、总结

该方案特点：

✅ 通用（适用于所有引擎）
✅ 不需要逆向
✅ 实现难度适中

缺点：

❌ OCR 有误差
